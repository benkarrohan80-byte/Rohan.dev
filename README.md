# Portfolio Website

This is a modern portfolio website built with React, TypeScript, and Tailwind CSS.

## Deployment to GitHub Pages

1. Upload all files from this folder to a new GitHub repository.
2. The included GitHub Action (`.github/workflows/deploy.yml`) will automatically build and deploy the site.
3. Once the action finishes, go to **Settings > Pages** in your GitHub repository and ensure the source is set to the `gh-pages` branch.

## Features
- Responsive Design
- Firebase Integration for Inquiries
- Modern UI with Motion Animations
- Custom Branded Logo
